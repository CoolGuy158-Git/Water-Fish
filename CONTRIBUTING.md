# Contributing to Water-Fish

---

## How to contribute

1. Fork the repo
2. Clone your fork:
```bash
git clone https://github.com/YOUR-USERNAME/YOUR-FORK-NAME
```
3. Create your changes
4. Make sure your branch is up to date with main before submitting a PR
5. Make a PR with a short but complete description of the changes

---

## What to contribute
- Help in fixing any bugs you find
- Improving documentation
- Suggesting features
- You can also choose things to do from the following TODO list

## Coding Guidelines
- Keep the code clean
- Follow the existing code style to keep changes readable and easy to review
- Please keep most or all of the variable/func name Camel Case
- Don't break existing features and make sure your code actually works (Test your changes before submitting a PR)

***If your  code doesn't follow these guidelines, I will not merge your PR and you will have to change your code to fit with these guidelines***

---

## Reporting bugs
When reporting bugs, include:
- What happened
- What you expected
- Steps to reproduce
- Screenshots

## Code of Conduct
Be respectful. No toxic behavior.
We're building a browser to connect the world, not to make humans fight even more.

## Thanks! 
Every contribution matters! Even small fixes help a lot.
