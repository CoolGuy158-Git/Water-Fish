# [WaterFish | One web, one world, one flow](info.html)

---

![WaterFish Logo](images/waterfish.png)

---

WaterFish is a lightweight very barebones web browser made in Python.  
Unfortunately, it only minimally or doesn't even support CSS/JS, which means most modern pages won't open.  
This project isn’t anything serious; I was just playing around with the idea of making a browser after recent privacy discussions around major browsers.  

Oh btw, the search engine used is [here](https://wiby.me/).

---

## More info
